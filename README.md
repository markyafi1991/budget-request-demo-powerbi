# Budget Request Demo — Power BI

**Version 0.1.0** · 2026-11-12 · Scaffold / not a completed demo

Part of the [complete project package](https://github.com/markyafi1991/budget-request-demo).

This is an entirely fictional portfolio scenario. No client data, credentials, private vault content or private repository history is included. The application and report have not yet been built or acceptance-tested.

## One-page report

Show budget, already-spent amount, approved requests, pending requests and available budget, with department filtering and a request-status breakdown. Use the hub's November 2026 synthetic fixtures. This is a request-and-budget view, not a full accounting or forecasting solution.
